# 🧠 AI News Lens (Real or Fake)

### 🧰 Tools & Technologies
**Python**, **Scikit-learn**, **TF-IDF**, **Logistic Regression**, **Streamlit**, **Plotly**

---

### 📘 Overview
AI News Lens is a **fake news detection web app** that classifies news headlines as *real* or *fake* using Natural Language Processing (NLP) and Machine Learning.  
It combines **TF-IDF text vectorization** with a **Logistic Regression model** for accurate and interpretable predictions, presented in a **Streamlit dashboard**.

---

### ⚙️ Features
- **Fake News Classification** — Detects if a news headline is real or fake  
- **TF-IDF Vectorization** — Converts text into numeric features for ML  
- **Model Explainability** — Visualizes important words using Plotly  
- **Interactive Dashboard** — Built with Streamlit for easy use  
- **Deployed** — Ready to host on Streamlit Cloud  

---
